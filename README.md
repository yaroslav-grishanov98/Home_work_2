# Проект - Class

## Описание: 
Class - проект содержит классы и функции для работы с категориями продуктов, загружаемых из JSON-файла

## Установка:
1. Клонируйте репозиторий:
git clone .............
2. Установите зависимости:
pip install -r requirements.txt

## Использование:
from models import load_categories_from_json

### class Product
Класс для описания продукта и его параметров

**Тесты**

* Тест корректной инициализации объекта Product

### class Category
Класс для описания категории 

**Тесты**:

* Тест правильной инициализации объекта Category

### Функция load_categories_from_json
Загружает продукты и категории из json файла

**Тесты**:

* Тест загрузки продуктов и категорий из json файла

### class category
Класс, описывающий категорию товаров

### Функция add_product
Добавляет товар в категорию

**Тесты**:

* Проверяет корректное добавление объекта Product в категорию
* Проверяет, что при попытке добавить в категорию объект не типа Product вызывается исключение

### Функция list_product
Возвращает список всех названий товаров в категории

### class products
Класс, описывающий товар

**Тесты**:

* Проверяет, что price корректно устанавливает положительное значение цены
* Проверяет, что при попытке установить цену 0 или отрицательную значение выводится предупреждение
* Проверяет, что при попытке снизить цену с подтверждением - цена меняется
* Проверяет, что при попытке снизить цену с отказом цена не меняется

### Функция new_product
Создает новый объект из словаря

**Тесты**:

* Проверяет создание нового объекта Product

### Функция __str__ для класса Category
Возвращает строковое представление категории

**Тесты**:

* Проверяет корректность строкового представления объекта Category

### Функция __add__ для класса Category
Позволяет сложить две категории

**Тесты**:

* Проверяет сложение двух объектов категории

### Функция __str__ для класса Product
Возвращает строковое представление товара

**Тесты**:

* Проверяет корректность объекта Product

### Функция __add__ для класса Product
Позволяет сложить два товара

**Тесты**:

* Проверяет сложение двух объектов продукта

### Подкласс Smartphone для класса Product

**Тесты**:

* Тестирует создание объекта Smartphone

### Подкласс LawnGrass для класса Product
